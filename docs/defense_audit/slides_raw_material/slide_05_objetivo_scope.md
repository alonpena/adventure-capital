# Slide 05 — Objetivo y alcance del MVP

Tiempo: 0:50.

Bullets:
- Construir pipeline local reproducible para evaluación startup.
- Incluir optimización, valorización, DD, reportes y UI artifact-driven.
- No alcance: SaaS productivo, due diligence legal, comparables de mercado automáticos.
- Output esperado: evidencia auditable para decisión experta.

Visual recomendado: matriz “incluido / fuera de alcance”.

Speaker notes: “La defensa debe ser precisa: esto es un MVP metodológico, no una plataforma SaaS completa.”
