# Slide 02 — Contexto: decisiones VC con información incompleta

Tiempo: 0:40.

Bullets:
- Startups tienen incertidumbre alta y datos incompletos.
- La evaluación combina crecimiento, caja, unit economics y salida.
- El problema no es solo calcular: es hacer explícitos supuestos y evidencia.
- La decisión final sigue siendo humana.

Visual recomendado: embudo VC + bloques “supuestos -> plan -> valor -> riesgo”.

Speaker notes: “La herramienta no pretende eliminar incertidumbre; pretende ordenar la evidencia y hacer visible qué supuestos sostienen la valorización.”
