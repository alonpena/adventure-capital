# 0008 — UI Architecture: Consulting Tool, Not Dashboard

## Status
Accepted

## Context

The Streamlit UI (`app.py`) was built as an artifact browser MVP. It uses a
light generic theme disconnected from the dark `report.html` aesthetic. Pages
expose raw technical dataframes. The UI does not feel like a professional
consulting automation tool.

The product must be presented to a university evaluation committee and to
Alejandro Maureira (the startup founder/client) as a standardized consulting
process — not as a student prototype.

Two alternatives were evaluated:
- Migrate to FastAPI + React for full frontend control
- Redesign Streamlit UI in-place

## Decision

**Stay on Streamlit. Redesign in-place.**

Migration to FastAPI + React is deferred indefinitely. Demo timeline and risk
profile make it unviable for this sprint.

The UI redesign follows these principles:

### 1. Entry flow: Configuración → Run → Informe Ejecutivo
- Opening screen is always **Configuración** (load YAML, run pipeline)
- After successful run, UI navigates automatically to **Informe Ejecutivo**
- If a run already exists in session, open directly to Informe Ejecutivo

### 2. Informe Ejecutivo = iframe of report.html
- The `report.html` artifact is embedded via `<iframe>` as the primary view
- Accompanied by a PDF download button
- This is the client-facing deliverable, not a dashboard

### 3. Drill-down tabs: Bloomberg-moderate density
Supporting pages for interactive exploration. Each visualization accompanied by
McKinsey-style parametrized narrative text. Sections in order:

| Tab | Content |
|-----|---------|
| Clientes | Vista consensuada (A_base, meses 1–12) / Proyecciones (MILP, meses 13–36) / Unificada |
| Servicios | Composición y dinámica por servicio |
| Ingresos | Composición de ingresos compuestos (nuevos + recurrentes) por canal |
| Costos | CAC detallado (prioridad), RRHH y administración resumidos |
| Flujo de caja | Mensual + anual, gráficos + tabla |
| Unit Economics | LTV, CAC, LTV/CAC, payback — con trazabilidad de fórmulas |
| Valorización | DCF completo, múltiplos de referencia, análisis de sensibilidad |
| Due Diligence | Veredicto + findings detallados + levers recomendados |
| Stochastic | Monte Carlo ex-post (solo si DD lo permite) |

### 4. Parametrized narrative
All section text: template strings with `{variable}` placeholders filled from
artifact data, plus conditional tone rules (positive/warning/critical) based on
business metric thresholds. Reproducible and auditable. Not LLM-generated.

AI agent-generated qualitative narrative is documented as **Trabajo Futuro**.

### 5. Downloadable artifacts
| Artifact | Format |
|---------|--------|
| Informe ejecutivo | PDF (from report.html) |
| Plan de crecimiento acelerado | Excel (.xlsx) + PDF |
| Unit economics workbook | Excel (.xlsx) + PDF |
| Valorización DCF | HTML + PDF |
| Due diligence | PDF |
| Sensitivity analysis | PDF |

Baseline for all: PDF. Excel is required for growth plan and unit economics
(Alejandro works in Excel templates).

### 6. Visual identity
Match `report.html`: background `#0B1020` (dark slate), KPI values `#F59E0B`
(amber), borders `#1F2937`. Pitchbook aesthetic for the iframe view, Bloomberg-
moderate density for drill-down tabs. Zero generic Streamlit blue.

### 7. Backend generates, UI only displays
The UI never recomputes model logic. All artifacts generated by the pipeline
backend (`postprocessing.py`, `standard_report.py`). Formula traceability
preserved in artifact schema — this is the core value proposition of the tool.

## Consequences

- `postprocessing.py` must emit Excel artifacts for growth plan and unit economics
- A new `narrative.py` module in postprocessing emits `narrative_data.json` per
  section with parametrized text templates + conditional rules
- `styles.py` replaced with dark theme matching `report.html`
- `app.py` navigation restructured: sidebar shows Alejandro-first flow
- New page: `informe_page.py` for iframe + PDF download
- All existing pages refactored for dense layout + narrative text

## Not in scope
- FastAPI / React migration
- Robust stochastic optimization (Trabajo Futuro)
- AI-generated qualitative narrative (Trabajo Futuro)
- SaaS deployment
