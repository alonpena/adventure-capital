## Legacy Paste Caveat

The pasted legacy output contains internally inconsistent sections:

- The MVP summary and monthly plan use the default/base-like model with ticket `700`, frequency `3`, churn year 1 `0.5`, and total revenue `USD 3,004,898`.
- The pasted DCF and unit economics section appears to come from a different parameter set or stale notebook state:
  - Unit economics shows ticket `USD 300`, recurrence monthly `1.00`, and churn `40.0%`.
  - DCF annual revenue totals `USD 3,718,297`, which does not reconcile with the MVP summary revenue `USD 3,004,898`.
  - DCF annual `G_adm` and `RRHH` totals differ from the base config used in the MVP summary.

Because the legacy notebook has top-level execution and multiple reruns, the MVP summary is the reliable baseline for `configs/base.yaml`. DCF/unit economics should be compared only against a legacy run where all cells use the same parameter set as the MVP summary.
